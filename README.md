# Shotty

Outil de capture d'écran et d'annotation pour Windows 10 et 11.

Ce dépôt ne contient que les installateurs. Télécharge `Shotty_x.y.z_x64-setup.exe` dans [la dernière version](https://github.com/Floopers80/shotty-app/releases/latest), puis lance-le : l'installation se fait pour l'utilisateur, sans droits administrateur. Shotty se met ensuite à jour tout seul (Réglages > À propos, ou le menu de son icône).
